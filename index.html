# วัน-เวลา รหัสอุปกรณ์ ผู้ตรวจเช็ก สถานะ ภาพถ่ายหลักฐาน หมายเหตุ

💾 ระบบสำรองและโอนย้ายข้อมูล (Data Backup & Migration)

ท่านสามารถดาวน์โหลดฐานข้อมูลอุปกรณ์ทั้ง 56 จุด พร้อมประวัติการตรวจสอบทั้งหมดออกมาเป็นไฟล์ JSON สำรองไว้ และสามารถนำไฟล์นี้ไปอิมพอร์ตเข้าสู่ระบบใหม่หรือระบบของโรงพยาบาลในอนาคตได้ทันที 100%

⚙️ การเชื่อมต่อกับฐานข้อมูลโรงพยาบาล (Firebase Cloud Setup)

ระบบปัจจุบันรองรับการทำงานทั้งแบบ Local Offline Demo และ Google Firebase Real-time Cloud
หากต้องการเชื่อมต่อกับฐานข้อมูลของหน่วยงาน เพียงเปิดไฟล์ firebase-config.js แล้ววาง Config ที่ได้จาก Firebase Console ของโรงพยาบาล
